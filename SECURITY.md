# Security

masstin reads evidence that may have been prepared by an attacker: a crafted EVTX, image, triage or log that makes it crash, hang, write outside its output or run anything is a security bug.

## Reporting a vulnerability

Please report it privately through GitHub: **Security › Report a vulnerability** on this repository. Do not open a public issue for it.

Say which version (`masstin --version`), on which system, and how to reproduce it; a sample file helps, with nothing from a real case in it. You will get an answer, and the fix goes in the next release with credit to you unless you prefer otherwise.

## Supported versions

Only the latest release gets fixes.
